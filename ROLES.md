# Development Process 
## Personas

**1. Development Manager** This role is filled by a person that defines process, sets goals, reviews everything, accountable for results
**2. Technical Supervisor** This role is filled by Cowork who deploys the process to produce the results that meet the goal. Any problems or gaps are to be flagged
  escalated to the Development Manager for resolution. Cowork passes tasks to Developers and verifies that acceptance criteria are met.
**3. Developers** These roles are filled by coding agents (for this project, Claude Code). Cowork gives each coding agent a single task which describes what is to be done,
  how is it tested and what the acceptance criteria are.
